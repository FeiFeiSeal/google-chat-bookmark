# ChatMark 0.2.0

## 新增與修正

- 支援獨立 `chat.google.com`，與 Gmail 內嵌 Chat 共用目前 Chrome Profile 的收藏及分類。
- 獨立 Google Chat 點選收藏時以頁面內切換返回訊息，避免透過分享連結重新載入整個網頁；Gmail 保留原有跳轉方式。
- Chrome 工具列圖示的右鍵選單提供「ChatMark 官網與使用說明」。
- 側欄底部提供「ChatMark 官網與使用說明」；兩個入口皆以新分頁開啟官網。

## 網站更新

- 官方網站網址改為 `https://chat-mark.josui.space/`；擴充功能入口、canonical、語言對應、社群分享網址、結構化資料、sitemap 與本機 CNAME 同步更新。

- 中英文首頁同步介紹兩個網站的支援範圍、共用收藏庫、頁面內跳轉及再次查閱說明的方式。
- 同步首頁標題、搜尋摘要、社群分享資訊及 SoftwareApplication 描述。
- 頁首語言切換置於最右側，使用獨立分段選擇器，僅顯示繁體中文與 English 選項，並標示目前語言；更新入口、政策及 GitHub 連結位於其左側。
- 中英文隱私政策補充官網入口、開啟時機與不附帶收藏資料的網址行為。
- 網站首次造訪顯示 0.2.0 更新彈窗，內容介紹獨立 Google Chat 支援與官方網站入口，不列出整頁重載修正；關閉後以網站 localStorage 記錄已閱版本；頁首「本次更新」可再次查看，中英文共用已閱狀態。網站無法儲存資料時仍可正常關閉彈窗，但下次造訪可能再次顯示。

## 發布順序

依使用者 2026-11-13 指示，本次網站內容先保留在本機，不推送遠端或發佈。套件審核狀態尚未在此確認，不將本機完成視為審核通過。

1. 確認 Chrome Web Store 的 0.2.0 套件審核通過，且包含上述功能的版本已可供使用者取得。
2. 再依使用者指示推送網站變更並發佈，核對中英文介紹與隱私政策。
3. `site/**` 推送至 `main` 會自動觸發現有 GitHub Pages workflow；審核通過前不得為了發布其他修改而一併推送這批網站內容，也不手動觸發部署。
