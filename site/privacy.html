隱私權政策

最後更新：2026 年 11 月 2 日

你的收藏，保存在你的瀏覽器。

ChatMark — Bookmarks for Google Chat™ 協助你在 Gmail 內嵌的 Google Chat 收藏、整理及返回重要訊息。本政策說明這項擴充功能如何處理資料，以及你可以如何管理資料。

ChatMark 是獨立開發的非官方擴充功能，並非由 Google 提供、贊助或背書。

收藏資料儲存在目前 Chrome 使用者設定檔的本機空間。擴充功能沒有開發者端的收藏資料伺服器，也沒有廣告、分析或追蹤服務。

我們處理哪些資料

當你在 Google Chat 訊息上按右鍵時，擴充功能會在頁面記憶體中暫存目標訊息的文字摘要與識別資訊，供你接著選擇收藏。選擇收藏後，會在本機保存：

  • 訊息定位資訊：對話類型、聊天室或對話 ID、討論串 ID、訊息 ID 與訊息連結，用於識別重複收藏及返回原訊息。
  • 收藏內容：由訊息文字產生的預設標題，以及你編輯的標題、筆記和分類名稱。
  • 整理與操作資訊：分類、排序、置頂與展開狀態，及建立、更新和最近開啟收藏的時間。

擴充功能也會讀取已授權 Gmail／Chat 分頁的網址，判斷側欄是否可用及執行訊息導覽。它不建立其他網站的瀏覽歷史，也不讀取你的 Google 密碼或登入 Cookie。

收藏標題或筆記可能包含你選定訊息中的個人資訊；這些內容同樣依本政策在本機處理。

資料如何儲存與使用

資料僅用於收藏、搜尋、分類、編輯、排序、置頂、返回訊息、復原操作及備份還原。收藏庫保存在 chrome.storage.local；部分復原資料暫存在 chrome.storage.session 或介面記憶體中。還原期間也會建立本機暫存副本，供中斷恢復使用，完成還原或恢復後清除。

擴充功能不使用 Chrome Storage Sync 自動同步收藏，也不會將收藏內容自動傳送給開發者或第三方。我們不出售收藏資料，不將它用於廣告、信用評估或與收藏功能無關的用途。

當你開啟收藏時，Chrome 會前往對應的 Google Gmail／Chat 網址；Google 會依其服務與隱私權政策處理該次連線。能否查看原訊息，仍取決於你的 Google 帳號及對話存取權限。

手動備份與還原

選擇「完整備份」時，擴充功能會將收藏庫下載為 JSON 檔案，其中包含收藏標題、筆記、訊息連結、識別資訊、分類與排序等資料。備份檔案沒有由擴充功能額外加密，請保存在你信任的位置。

還原只會讀取你主動選擇的檔案，驗證後經你確認，才取代目前收藏庫。備份與還原都在本機進行。若你自行分享備份，接收者可以讀取檔案內的內容；擴充功能不會自動分享它。

管理、保存與刪除資料

你可以在側欄查看、編輯或刪除收藏與分類，也可以匯出備份。收藏庫會持續保留，直到你刪除、以還原取代，或清除擴充功能資料。刪除收藏不會刪除 Google Chat 中的原始訊息。

為支援「復原」，已刪除或變更的內容可能暫留在復原記錄中；頁面記憶體及工作階段資料會隨其生命週期清除。移除擴充功能會清除該擴充功能的本機儲存資料，但不會刪除你已下載、複製或分享的備份檔案；這些檔案需要由你另外刪除。

開發者無法遠端存取或替你還原本機收藏。擴充功能未對本機收藏另加密或提供密碼保護，請使用你信任的裝置與 Chrome 使用者設定檔。

保存本機收藏、分類、介面狀態與復原操作所需資料。

在 Gmail 分頁顯示收藏管理介面。

在 Gmail 內嵌的 Chat 框架中辨識你右鍵操作的訊息，取得收藏資訊並顯示操作回饋。

診斷資訊與支援

遇到錯誤時，你可以主動複製診斷資訊。它包含頁面類型、框架編號、處理階段及錯誤代碼，不包含訊息文字、筆記、參與者或網頁 DOM。擴充功能不會自動送出診斷資訊。

若你主動透過 GitHub Issues 聯絡我們，開發者與 GitHub 會收到你提交的內容，並用於回覆問題與提供支援。公開 Issue 的內容也可被其他人看到，請勿貼上私人對話、完整備份或登入資訊。

這個政策網站

本頁透過 GitHub Pages 提供，未加入分析程式、追蹤工具或外部字型。瀏覽本頁時，GitHub 可能依其隱私權聲明處理 IP 位址及網站存取紀錄。這些網站連線與擴充功能中的本機收藏資料是不同的資料處理。

資料使用承諾與政策更新

ChatMark 對使用者資料的使用遵循 Chrome Web Store 使用者資料政策，包括 Limited Use（有限使用）要求。資料僅用於本政策所述的使用者功能，不用於個人化廣告，也不出售給資料仲介。

功能或資料處理方式變更時，我們會更新本頁與上方日期；若變更依法或依平台政策需要另外告知或取得同意，會在相關資料處理前完成。
